THE EXPERIENCE

How we’ll work together.

We’ll work on your task during the calls. I’ll help you set up the agent, test the results, and improve the instructions. You’ll have time to ask questions and see how other people are approaching their tasks.

We’ll talk through the real decisions, too: what you’re comfortable handing over, what still needs your judgment, and when checking the work takes more effort than doing it yourself.

THE SIX WEEKS

Your six weeks, step by step.

You’ll work on the same task throughout. Between calls, try what we’ve covered and bring the results back.

  1. 01

    Choose your task

    Set up your tools and choose a task for your first agent.

  2. 02

    Define a good result

    Gather the information and examples that show your agent what a good result looks like.

  3. 03

    Build the first version

    Write the instructions, run the task, and review the first results.

  4. 04

    Test the tricky cases

    Try requests with missing information. Decide when the agent should stop and ask you.

  5. 05

    Run the work regularly

    Choose which steps can run on a schedule and which need your approval.

  6. 06

    Keep your agent useful

    See what ran, spot problems, and update the agent as your needs change.

You’ll leave with an agent built around your task, a way to check its work, and the skills to keep improving it.
